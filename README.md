# KaloriNetto

Energibalans över tid: håller koll på nettot i kaloriintag mot ett förinställt dagsbehov. Dagar utan inmatning räknas som att man ätit precis sitt behov.

Appen är en enda fil (`index.html`) och sparar allt lokalt i webbläsaren.

## Versioner

Versionsnumret visas längst ned i appen.

- `0.x` – ofärdiga versioner under arbete. Andra siffran höjs ett steg för varje ny publicering här (0.1 → 0.2 → 0.3 …).
- `1.0` – den dag appen anses färdig. Därefter `1.1`, `1.2` för mindre uppdateringar och `2.0` för stora förändringar.

Alla tidigare versioner finns kvar:

- Git-etiketter (tags): `v0.1`, `v0.2` … – under *Releases/Tags* på GitHub.
- `arkiv/v0.1/index.html` – första versionen, orörd.

Webbadressen visar alltid den senaste versionen.
